# Task Manager — Vue 3 + Pinia + Ant Design Vue (SIS 5)

Приложение для управления задачами.

- **Vue 3** (Composition API, `<script setup>`)
- **Pinia** — хранилище задач, фильтра и поиска (`src/stores/tasks.js`)
- **Ant Design Vue** — все UI-компоненты
- **Composables** — `src/composables/` (форма, фильтры, localStorage)

## Запуск
```bash
npm install
npm run dev
```
